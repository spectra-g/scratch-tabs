V1.14.0

LATEST
2025-12-29

🔗 SHARE_TABS_API

Share tab content via shareable URLs with intelligent compression, smart trimming for large content, and hash-based routing that guarantees zero-knowledge privacy.

# new_features

  • + Share Tab URLs: Generate shareable URLs from any tab - compressed content embedded directly in the URL.
  • + Structure-Aware JSON Trimming: Selective data sharing while maintaining valid JSON structure.
  • + Hash-Based Privacy: URLs use hash fragments (#) ensuring content never appears in server logs.
  • + Visual Size Feedback: Real-time color-coded budget bar for URL length limits.

# privacy_security

  • > Zero-Knowledge: Hash routing ensures shared content exists only in browser memory.
  • > Pure Client-Side: No third-party services, APIs, or tracking used for sharing.
